# End-to-End Data Platform

This project demonstrates an end-to-end modern data platform using:

- Python Scraping
- Snowflake
- dbt
- Apache Airflow
- Metabase

## Architecture

Python Scraping
    ↓
Snowflake Bronze
    ↓
dbt Silver
    ↓
dbt Gold
    ↓
Metabase Dashboard
    ↓
Airflow Orchestration

## Technologies

- Python
- Snowflake
